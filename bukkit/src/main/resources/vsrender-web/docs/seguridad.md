# Seguridad y respaldos
La web escucha solo en 127.0.0.1:3050, apagada por defecto.
El enlace contiene un token secreto. No lo compartas.
Se generan respaldos en .vsrender-web-backups antes de editar o borrar archivos existentes.
Para abrir desde otro equipo, usá un túnel SSH; no expongas el puerto a Internet.
