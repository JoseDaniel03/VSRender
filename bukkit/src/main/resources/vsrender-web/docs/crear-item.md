# Crear contenido en VSRender

1. Abrí el panel usando `/vsr web start`.
2. Creá o seleccioná un pack desde la sección Packs.
3. En **Plantillas**, elegí un tipo: objeto, ingrediente, herramienta, equipable, bloque, mineral, mueble, alimento, bebida, plato o cultivo.
4. Elegí un material base compatible, un nombre, un ID y, opcionalmente, una textura personalizada.
5. Completá los parámetros de la categoría (durabilidad, ranura, dureza de bloque, etc.) y guardá.
6. Presioná **Aplicar al juego**; verificá el resultado dentro de Minecraft 26.3.

Cada plantilla reutiliza el motor de ítems, bloques, muebles o recetas de VSRender. Los bloques se generan como ítem colocable + definición de bloque en un mismo archivo. Las recetas se crean en Crafting Studio por separado.
