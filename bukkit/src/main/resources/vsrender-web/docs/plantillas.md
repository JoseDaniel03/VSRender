# Plantillas
Ingrediente: nombre y material.
Alimento: nutrición, saturación y material.
Bebida: usar material consumible compatible y verificar los recipientes.
Plato genérico: una definición para sopa, guiso, ensalada o tarta.
## Cultivos
Las semillas, etapas y loot requieren un bloque crop_block; el ejemplo completo sigue disponible en el ZIP de plantillas Cocina. Todavía no se generan automáticamente en la web.
